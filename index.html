                        Auto-Log Bank SMS on iPhone

                        Apple blocks all apps from reading SMS directly, so you connect it using iPhone's built-in Shortcuts app:

                        1. Open Shortcuts → tap Automation → tap +.
                        2. Choose Message, set Message Contains to debited (or Credit Card), and pick Run Immediately.
                        3. Add action URL Encode (Input: Shortcut Input).
                        4. Add action Open URLs pointing to your hosted QuickSpend link with ?sms= + the encoded text.

                        When QuickSpend opens with ?sms=..., it detects Debit vs. Credit Card, converts foreign currency to QAR, categorizes it, and updates the right balance.
